# SedaDizi – Modern Pembe & Violet Asya Dizi Platformu

SedaDizi (senadizi.com), Kore (K-Drama), Çin (C-Drama) ve Tayland dizilerini Türkçe altyazı ve dublaj seçenekleriyle sunan modern, hızlı ve responsive bir web platformudur.

## 🚀 Özellikler
- **20 Popüler Asya Dizisi:** Queen of Tears, Marry My Husband, Squid Game 2, The Glory, Love Next Door, Lovely Runner, Hidden Love vb.
- **Çoklu Sunucu (Multi-Server) Oynatıcı:** Server 1 (HD Hızlı), Server 2 (VIP Hızlı), Server 3 (Embed Iframe).
- **Otomatik Asya Dizi & Embed Botu (`cron_bot.py`):** Multi-source scraper (Dramafilix, Dramakolik, Liderdrama, Dramacix, Dramadizilerim).
- **Güvenli Webhook API:** `/api/cron/update-dramas?key=SENADIZI_SECRET`
- **Global DMCA 512(c) Telif Kalkanı:** Yer sağlayıcı bildirim ve takedown protokolü.
- **Çapraz Tarayıcı:** iOS Safari, Android Chrome, Edge, Firefox uyumlu.

## 🛠️ Kurulum & Çalıştırma
```bash
npm install
npm start
```
veya Python FastAPI ile:
```bash
pip install -r requirements.txt
python main.py
```
